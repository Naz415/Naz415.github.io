# Naz's Network+ Lab Notebook

Source for [naz415.github.io](https://naz415.github.io): lab walkthroughs from the Calbright College Network Technology program (CompTIA Network+ N10-009).

- `_posts/` one post per lab
- `_drafts/TEMPLATE-lab-post.md` copy this to start a new post
- `configs/` saved device configs from each lab, one folder per lab
- `cheatsheet.md` the Cisco IOS commands the Module 11 labs use
- `assets/img/` screenshots, one folder per lab

Built with Jekyll (Minima theme) on GitHub Pages.
